# 🤖 Jira Telegram Bot

> Управляйте задачами Jira прямо из Telegram — быстро, удобно и эффективно!

## 📋 Описание

Telegram-бот для работы с Jira, который позволяет управлять задачами, получать уведомления об изменениях и работать с фильтрами без необходимости открывать веб-интерфейс.

---

## ✨ Основные возможности

### 📊 Управление задачами

- **Просмотр задач по статусам** — видите все свои задачи, сгруппированные по текущему статусу
- **Детальная информация** — полное описание задачи, автор, ответственный, статус
- **Быстрое редактирование** — изменяйте задачи прямо из чата

### 🔄 Изменение статусов

- **Доступные переходы** — бот показывает только те статусы, на которые можно перейти
- **Умная фильтрация** — автоматически скрывает переходы, требующие заполнения дополнительных полей
- **Уведомления** — ответственный получает уведомление об изменении статуса

### 👥 Работа с исполнителями

- **Смена ответственного** — назначайте задачу другому пользователю
- **Автоуведомления** — новый ответственный моментально получает уведомление о назначении

### ⏱ Учёт времени

- **Логирование работы** — добавляйте затраченное время в формате `2h 30m` или `1d 4h`
- **История времени** — просматривайте все записи о затраченном времени
- **Детализация** — видите кто, когда и сколько времени потратил

### 🔎 Умные фильтры

- **Создание фильтров с ИИ** — опишите своими словами какие задачи нужно найти, бот создаст JQL-запрос автоматически
- **Ручной JQL** — продвинутые пользователи могут вводить готовые JQL-запросы
- **Подписки на фильтры** — получайте уведомления о новых задачах в выбранных фильтрах
- **Быстрый доступ** — сохраняйте часто используемые поисковые запросы

### 🔔 Система уведомлений

#### Уведомления о задачах
- Изменение статуса ваших задач
- Назначение вас ответственным
- Обновления в задачах из подписанных фильтров

#### Уведомления о комментариях
- Новые комментарии в ваших задачах
- Показывается автор и начало текста комментария
- Можно отключить отдельно от основных уведомлений

#### Гибкие настройки
- Включение/отключение всех уведомлений
- Раздельное управление уведомлениями о комментариях
- Проверка обновлений каждые 5 минут

### 🙈 Скрытие статусов

- **Персонализация** — скрывайте неактуальные статусы из основного списка
- **Быстрый доступ** — скрытые статусы остаются доступными в отдельном разделе
- **Гибкость** — показывайте и скрывайте статусы в один клик

### 🧭 Удобная навигация

- **Пагинация** — удобный просмотр длинных списков задач
- **Контекстные кнопки "Назад"** — всегда возвращайтесь туда, откуда пришли
- **Запоминание позиции** — бот помнит, на какой странице вы остановились

## 🚀 Начало работы

### 1. Авторизация

```
/login
```

Бот попросит вас создать Personal Access Token в Jira:
1. Перейдите в настройки профиля Jira
2. Создайте новый токен
3. Скопируйте и отправьте боту

### 2. Главное меню

После авторизации вам доступны три основных раздела:

- 📋 **Мои задачи** — просмотр и управление задачами
- 🔎 **Мои фильтры** — сохранённые поисковые запросы
- 🔔 **Настройки уведомлений** — управление оповещениями

---

## 💡 Примеры использования

### Быстрый просмотр задач

1. Нажмите **📋 Мои задачи**
2. Выберите интересующий статус
3. Откройте нужную задачу
4. Вся информация перед вами!

### Изменение статуса задачи

1. Откройте задачу
2. Нажмите **🔄 Сменить статус**
3. Выберите новый статус из доступных
4. Готово! Ответственный получит уведомление

### Создание фильтра с помощью ИИ

1. Откройте **🔎 Мои фильтры**
2. Нажмите **➕ Добавить фильтр**
3. Опишите своими словами:
   - "задачи за последние 7 дней, которые были завершены"
   - "все баги в статусе In Progress"
   - "задачи с высоким приоритетом без ответственного"
4. Бот создаст JQL-запрос и сохранит фильтр

### Подписка на обновления

1. Создайте нужный фильтр
2. Нажмите на иконку 🔕 рядом с фильтром
3. Иконка изменится на 🔔
4. Теперь вы получаете уведомления о новых задачах!

|---------|----------|

| `/login` | Авторизация через API токен |

## 🔐 Безопасность

- Все токены хранятся локально на сервере
- Бот не имеет доступа к вашему паролю Jira
- Используется официальный API Jira
- Токены можно отозвать в любой момент через настройки Jira

## 🛠 Технические особенности

### Архитектура

- **Node.js** — основная платформа
- **node-telegram-bot-api** — работа с Telegram API
- **axios** — HTTP-клиент для Jira API
- **OpenAI API** — генерация JQL-фильтров

### Модульная структура

```
├── config/         # Конфигурация
├── handlers/       # Обработчики команд и событий
├── services/       # Бизнес-логика (Jira, уведомления, AI)
├── utils/          # Вспомогательные функции
└── views/          # Формирование интерфейса
```

### Хранение данных

- Данные пользователей сохраняются в JSON-файле
- Автоматическое сохранение при каждом изменении
- Персистентность состояния между перезапусками

## 📊 Возможности для продвинутых пользователей

### JQL-запросы

Если вы знакомы с JQL (Jira Query Language), можете создавать фильтры напрямую:

```
project = "MYPROJECT" AND status = "In Progress" AND assignee = currentUser()
```

### Форматы времени

При логировании работы поддерживаются форматы:
- `2h` — 2 часа
- `30m` — 30 минут
- `2h 30m` — 2 часа 30 минут
- `1d` — 1 день (8 часов)
- `1d 4h` — 1 день и 4 часа
